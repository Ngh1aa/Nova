User flows

Decision → action → feedback → recovery.

The portfolio demo concentrates depth on the moments where a banking interface can mislead users: risk alerts, freeze consequences, irreversible transfer review, authentication failure and offline recovery.

Flow contract

Every critical flow includes trigger, entry, decision, action, system feedback, success/error and recovery. No state may imply money moved when confirmation failed.
