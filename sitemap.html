Information architecture

Five daily destinations, context when needed.

Primary mobile navigation stays at Home / Activity / Pay / Cards / Save. Money Health, subscriptions, notifications and security appear contextually so the app does not become a six-tab catch-all.

Navigation rule

Global nav is intentionally small. High-risk controls appear in the transaction/card context where the user has enough evidence to understand consequences.
