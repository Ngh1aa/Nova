# Nova Round 01 — Session Evidence Folder

Only **completed, anonymized** session records belong here.

Do not pre-create `P01.md`–`P05.md` as if sessions already happened. Duplicate `../SESSION-TEMPLATE.md` only after a real session has taken place and the notes are ready to be committed.

## File naming

- `P01.md`
- `P02.md`
- `P03.md`
- `P04.md`
- `P05.md`

Participant IDs are study-local anonymous identifiers. They must not be mapped to real identities inside this repository.

## Required before commit

Each session file must include:
- participant criteria confirmed;
- consent state;
- date and mode;
- exact prototype version/commit;
- task outcomes;
- observable behavior;
- moderator assistance;
- quotes marked verbatim or paraphrase;
- contradictory or failed behavior when observed;
- completed session-integrity checklist.

## Never commit

- names or contact details;
- account numbers, balances, credentials, OTPs or real transaction data;
- screenshots or recordings containing real banking information;
- invented quotes, outcomes, timings or participant attributes;
- AI-generated substitutes for missing observations.

## Promotion rule

A file appearing in this folder does not automatically make it verified evidence. The record must pass the integrity checklist and then be referenced from `../EVIDENCE-REGISTER.md`. `../status.json` remains `PLANNED` until the full study promotion gate passes.
