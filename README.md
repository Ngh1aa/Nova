# Nova — Personal Banking & Money Planning

Nova is a portfolio-grade consumer fintech prototype focused on **safe-to-spend decision support**, Money Horizon planning, transaction trust, card controls, transfers, savings, subscriptions, KYC and recovery.

## Prototype

Open `prototype.html` for the guided recruiter demo, or `app.html?screen=home` for the product.

### Core demo flows

- Home → suspicious transaction → transaction detail → freeze card → confirmation
- Home → transfer → recipient → amount → review → biometric → success
- Failure/recovery: insufficient balance, offline, biometric failed
- Onboarding/KYC: capture guidance, quality failure, manual-review recovery

## User validation — Round 01

**State: RECRUITING / PLANNED — 0 verified sessions.**

Nova does not currently claim user validation. The moderated study is designed to test whether people correctly interpret Money Horizon, understand what is safe to spend, protect an account after an unusual transaction, review transfer impact and recover from failure.

Research artifacts:

- `research/validation/nova-round-01/status.json` — machine-readable evidence state and claim rules
- `research/validation/nova-round-01/STUDY-PLAN.md` — participant criteria, tasks, measures and moderator protocol
- `research/validation/nova-round-01/SESSION-TEMPLATE.md` — anonymized raw session record
- `research/validation/nova-round-01/EVIDENCE-REGISTER.md` — finding/metric provenance and portfolio promotion gate

Only real, anonymized participant observations can move the evidence state from `PLANNED` to `VERIFIED_FOR_ROUND`. AI may help cluster notes but may not invent participants, quotes, counts or outcomes.

## Reality boundary

All account values and banking operations are **prototype data / simulated behavior**. No production banking service is connected. No conversion, retention, usability improvement or financial outcome is claimed without retained evidence.
